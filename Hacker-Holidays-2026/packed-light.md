# Step 6: brute forcing the XOR key 

Instead of guessing keys one at a time, I wrote a script to try every possible single byte key from 0 to 255 against the decoded bytes and only print the ones that came out as fully readable ASCII. 

raw_bytes = bytes.fromhex("1c0005331e7b3a7c17793b173f7c3c2b2079262f17783e2d1a1731783d35") for key in range(256): decoded = bytes(b ^ key for b in raw_bytes) try: text = decoded.decode("ascii") if all(32 <= c < 127 for c in decoded): print(f"key={key:3d} (0x{key:02x}): {text}") except UnicodeDecodeError: pass 

This printed a handful of results, but one of them was obviously the right one because it read as a clean sentence rather than random symbols. Key 72, or 0x48, gave: 

THM{V3r4_1s_w4tch1ng_0veR_y0u} 

# Where I got stuck 

The bit that actually slowed me down the most was realising the URL itself was not carrying any data at all, since I kept staring at the <mark>GET /</mark> line expecting something to be encoded there. It took a bit of digging around in the headers before I properly looked at the cookie value and noticed it kept changing. Also had a small detour sorting out tshark not being recognised as a command, which was just a PATH issue in the end. 

# TL;DR 

- Used Statistics then Endpoints in Wireshark to spot the standout external IP talking to the guest machine. 

- Filtered on that IP plus http and noticed a long run of identical looking GET requests happening about once a second. 

- Found a cookie called hotel_sess_state that changed value on every request, which was the actual hidden channel. 

- Used tshark to pull every cookie value out in order instead of clicking through each packet by hand. 

- Base64 decoded each value, which gave one byte per request, then joined them all together. 

- Brute forced a single byte XOR key against the joined bytes until one came out as readable text. 

- Flag was THM{V3r4_1s_w4tch1ng_0veR_y0u} 

Overall a good room for practicing actually reading through a capture properly instead of just looking for the obvious stuff. Took me longer than I expected for an easy rated room, but the whole chain of Wireshark, tshark, and a couple of small Python scripts felt like a genuinely useful workflow to have for anything similar in the future.
